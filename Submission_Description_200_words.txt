This project demonstrates MQTT-style communication for an Internet of Things environment using three simulated sensor nodes: temperature, humidity, and light. Each node publishes ten readings to its own topic through a central broker, while a monitoring dashboard subscribes to the topics. The Python simulation models the publish/subscribe workflow and records message delivery status and network latency. A controlled message-failure probability is included to examine communication reliability under imperfect network conditions. The generated CSV file contains detailed results for all thirty messages, and a summary file reports the total number of messages, delivered and failed messages, delivery rate, and latency statistics. A fixed random seed makes the experiment repeatable. The report explains the protocol choice, architecture, configuration, methodology, performance evaluation, error handling, limitations, and troubleshooting steps. This is an educational software simulation of MQTT-style behaviour rather than a live MQTT broker implementation; therefore, latency and delivery values are simulated and are not physical network measurements. The project can be extended by connecting real MQTT clients to a broker such as Mosquitto or by building the same flow in Node-RED. The project is intended for learning and documentation, and the source code is included so the simulation settings and generated output can be inspected and reproduced by the evaluator.
